**AI Semantic Book Search System**

一個以 **FastAPI + Pinecone** 建構的語意搜尋與推薦系統，
目的是提升書籍搜尋的**相關性、可信度與可解釋性**，
展示如何將向量模型（Embedding）真正落地為可用的資料產品。

---

**問題與目標**

傳統書籍搜尋依賴關鍵字比對，會出現下列問題：  

*使用者想找「內容相近」但不含關鍵字的書籍時，搜尋不準確  

*長文本資訊中雜訊高，容易被錯誤放大  

*推薦結果**無法解釋來源與可信度**  

本專案利用 **語意搜尋 + 可解釋調權 + 聚合策略**，
在 **不使用 LLM 生成內容、不冒產生不存在書籍風險** 的前提下，
打造一個「**可驗證、可信、能落地的推薦基礎引擎**」。



**系統流程與推薦邏輯**

使用者輸入查詢後，系統會：  
  
1.產生查詢向量（Embedding）  
2.以 Pinecone 進行語意搜尋  
3.將多段落結果聚合為單一本書  
4.依書名/分類等內容賦予可解釋權重  
5.進行去重與多樣化篩選  
6.輸出可信度較高的 Top-5 書籍  

**架構流程圖**
使用者查詢  
↓
Embedding（Local Model）  
↓
Pinecone 語意檢索（Vector Search）  
↓
聚合同書段落 → 書籍層級  
↓
可解釋權重 Re-score（Title / Category / Publisher / Body）  
↓
多樣化推薦與可信篩選  
↓
Top-5 書籍輸出  

FastAPI 另外提供 30 秒快取，避免大量相同請求造成搜尋成本浪費。  



****技術細節****

**主要架構**
Backend: FastAPI  
Vector DB: Pinecone  
Language Model: Sentence-Transformer / text-embedding model  
Language: Python 3.10+

**欄位前處理**
查詢與書籍 metadata 欄位（標題、分類、出版社）  
在查詢前進行：
- 正規化（lowercase、移除特殊符號）
- 斷詞（regex 或 jieba）

**權重設計 （Keyword Bonus）**

目的：權重只提升可解釋性，不主導語意搜尋。避免因調權造成推薦偏差。  

| 欄位 | 權重 | 理由 |
|--------------------------------------|-------|-------------------------------------------|
| 書名 (title)                          | 0.08 | 書名與查詢語意最接近，命中時幾乎可代表高相關性 |
| 分類 + 出版社 (category + publisher)   | 0.03 | 類別或出版社常具主題一致性，可作輔助依據      |
| 內文 (body)                           | 0.01 | 內文字詞雜、噪音多，只進行微調補強            |


**聚合與多樣化策略**

目的：提高資訊效率與探索價值，而不是「分數最高但全部很像」。    

1️⃣ 書籍層級聚合 (aggregate_by_book)

*將同一本書的多個段落（chunk）聚合為一筆(書籍)  
*僅保留最高分段落作為代表  
*加入權重設定後重新排序

2️⃣ 多樣化推薦 (diversify_by_title_or_cat)

*同書不重複  
*儘量避免相同分類重複  
*若不足 5 本，從其他候選中補齊
