**AI Semantic Book Search System**

一個以 FastAPI + Pinecone 建構的語意搜尋系統，  
能從書籍資料中進行語意檢索、聚合與多樣化推薦。  
此專案展示如何讓 AI 模型實際「落地」為可用的資料產品。

---

**專案簡介**

使用者輸入查詢文字後，系統會：

1. 產生查詢向量（Embedding）
2. 使用 Pinecone 進行語意查詢（Semantic Search）
3. 聚合同書段落結果（Chunk → Book）
4. 依照關鍵字匹配進行加權重排序（Weighted Re-score）
5. 去重與多樣化篩選，輸出最終 Top-5 書籍推薦

在fastAPI，有設定快取30秒。

**架構流程**

使用者查詢
↓
Embedding (Local model)
↓
Pinecone 語意檢索 (vector search)
↓
輸出結果整理聚合為書籍層級
↓
加權 (標題 0.08 / 出版社 + 分類  0.03 / 內文 0.01)
↓
去重複書籍 + 多樣化推薦
↓
輸出Top-5 書籍結果

****技術細節****

**主要架構**
Backend: FastAPI  
Vector DB: Pinecone  
Language Model: Sentence-Transformer / text-embedding model  
Language: Python 3.10+

**欄位前處理**
查詢與書籍 metadata 欄位（標題、分類、出版社）  
在查詢前進行：
- 正規化（lowercase、移除特殊符號）
- 斷詞（regex 或 jieba）

**權重設計 （Keyword Bonus） **
目的：微調語意分數，不干擾原始排序。

| 欄位 | 權重 | 理由 |
|--------------------------------------|-------|-------------------------------------------|
| 書名 (title)                          | 0.08 | 書名與查詢語意最接近，命中時幾乎可代表高相關性 |
| 分類 + 出版社 (category + publisher)   | 0.03 | 類別或出版社常具主題一致性，可作輔助依據      |
| 內文 (body)                           | 0.01 | 內文字詞雜、噪音多，只進行微調補強            |


**聚合與多樣化策略**

1️⃣ 書籍層級聚合 (aggregate_by_book)

*將同一本書的多個段落（chunk）聚合為一筆(書籍)  
*僅保留最高分段落作為代表  
*加入權重設定後重新排序

2️⃣ 多樣化推薦 (diversify_by_title_or_cat)

*同書不重複  
*儘量避免相同分類重複  
*若不足 5 本，從其他候選中補齊
